# Changelog

All notable AgentOps releases are documented here.

## 0.1.0 — Initial release

- Added Python and TypeScript SDKs with OpenTelemetry exporters, GenAI conventions, AgentOps correlation attributes, retries, and client-side redaction.
- Added a FastAPI service with SQLite persistence for spans, runs, evaluations, datasets, regression jobs, digest jobs, drift samples, and trace correlation.
- Added online, regression, and invariant evaluation workflows with relevance, faithfulness, structure, and cost templates.
- Added ADWIN, MMD, and PSI-based drift processing for input, tool-call, quality, and attribution signals.
- Added the AgentOps console for drift monitoring, traces, comparisons, evaluations, and datasets.
- Added a multi-agent arXiv research workflow, a dedicated digest UI, deterministic mock data, optional real-arXiv access, and figure serving.
- Added a framework-neutral Anthropic SDK instrumentation example.
- Added non-live Python and TypeScript test, lint, type-check, and production-build automation.
